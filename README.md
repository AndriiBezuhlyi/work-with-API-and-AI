# Сума транзакцій

## Запуск

1. Виконай `npm install`.
2. Створи `.env.local` за прикладом `.env.example` і вкажи ключі API (у поточній робочій папці вже налаштовано).
3. Виконай `npm run dev` і відкрий адресу з термінала.

`npm test` перевіряє розрахунки, `npm run build` створює збірку.

## Модулі

- `src/main.js` — керує завантаженням і показує результат `{ total, currency }` та помилки.
- `src/api.js` — паралельно завантажує два джерела через fetch; окремо отримує курси CurrencyFreaks.
- `src/transactions.js` — відбирає paid або транзакції без статусу, приводить дані до `{ amount, currency }`.
- `src/revenue.js` — рахує загальну суму в USD і початкові суми USD/EUR окремо.

## Правила розрахунку

Основна валюта завжди USD. Усі враховані транзакції конвертуємо в USD. Нижче показуємо окремі суми початкових транзакцій USD та EUR без конвертації; pending і rejected не враховуємо.

CurrencyFreaks повертає курси відносно USD: `сума / курс вихідної валюти`. Використовуємо поточні курси, а не історичні. Документація: https://currencyfreaks.com/documentation

Округлюємо підсумок до двох знаків. Якщо дані або потрібний курс некоректні, показуємо помилку замість часткової суми. Курси запитуємо один раз при завантаженні або оновленні сторінки: для конвертації та списку EUR, GBP, JPY, CHF, CAD, AUD, CNY. Показуємо дату курсів сервісу. Помилка курсів не приховує завантажені транзакції та їх початкові суми; підсумок лише з USD не залежить від курсів. Технічні помилки залишаються в консолі, на сторінці — зрозумілі повідомлення.

`.env.local` ігнорується Git, але змінні `VITE_*` доступні у браузері. Для публічного розгортання запити з ключами слід перенести на сервер.
