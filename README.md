# Сума транзакцій

## Запуск

1. Виконай `npm install`.
2. Створи `.env.local` за прикладом `.env.example` і вкажи ключі API (у поточній робочій папці вже налаштовано).
3. Виконай `npm run dev` і відкрий адресу з термінала.

`npm test` перевіряє розрахунки, `npm run build` створює збірку.

## Модулі

- `src/main.js` — керує завантаженням і показує результат `{ total, currency }` та помилки.
- `src/api.js` — паралельно завантажує два джерела через fetch; окремо отримує курси CurrencyFreaks.
- `src/transactions.js` — відбирає paid або транзакції без статусу, приводить дані до `{ amount, currency }`.
- `src/revenue.js` — обирає валюту і рахує суму після конвертації.

## Правила розрахунку

Порівнюємо кількість USD та EUR серед врахованих транзакцій з обох джерел. За рівності або відсутності цих валют обираємо USD. Інші валюти також конвертуємо в обрану, якщо є курс.

CurrencyFreaks повертає курси відносно USD: `сума / курс вихідної валюти * курс цільової валюти`. Це дозволяє отримати EUR без зміни базової валюти API. Використовуємо поточні курси, а не історичні. Документація: https://currencyfreaks.com/documentation

Округлюємо підсумок до двох знаків. Якщо дані або потрібний курс некоректні, показуємо помилку замість часткової суми. Якщо конвертація не потрібна, не запитуємо курси.

`.env.local` ігнорується Git, але змінні `VITE_*` доступні у браузері. Для публічного розгортання запити з ключами слід перенести на сервер.
